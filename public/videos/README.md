# NORDIX — ролик на главной

Этот каталог предназначен для пользовательского видео разборки холодильника.

**Требуется добавить:** `nordix-fridge.mp4` (присланный пользователем файл `output (1).mp4`, 21 419 986 байт).

Размещение: `public/videos/nordix-fridge.mp4`.

Видео показывается автоматически справа от основного текста на больших экранах,
под текстом — на узких. Автовоспроизведение без звука, повторы, скрытые элементы управления.

React-компонент `Hero` в `src/App.tsx` формирует ссылку с учётом
`import.meta.env.BASE_URL` (`/NORDIX/videos/nordix-fridge.mp4`).

При загрузке файла в GitHub веб-интерфейс открой нужную ветку, каталог
`public/videos`, используй **Add file → Upload files**.
Можно предварительно переименовать `output (1).mp4` в `nordix-fridge.mp4`.

**Внимание:** пока MP4 не загружен, браузер не сможет воспроизвести ролик;
наличие разметки видео само по себе не означает, что файл доступен.
